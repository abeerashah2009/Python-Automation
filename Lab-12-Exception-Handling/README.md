# Lab 12 – Exception Handling in Python

## Objective
Learn how to handle runtime errors using `try` and `except` blocks.

## Concepts Covered
- try and except
- ZeroDivisionError
- ValueError
- Handling invalid user input
- Preventing program crashes

## Practical Tasks

### Task 1 – Basic Division
Created a Python program to divide 100 by a user-provided number.

### Task 2 – Handle ZeroDivisionError
Used an `except` block to display a custom message when the user enters zero.

### Task 3 – Handle ValueError
Added another `except` block to handle non-numeric input.

## Test Cases

| Input | Expected Result |
|---|---|
| 0 | Error: Cannot divide by zero! |
| abc | Error: Please enter a valid number! |
| 4 | Result: 25.0 |

## File
- `div.py` – Python exception handling program.

## Learning Outcome
Learned how to handle common Python errors and make programs more reliable.
